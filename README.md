# Friday Evening

A pixel-art browser game set in a late-night bar. Play rock, paper, scissors against a mysterious stranger. The loser picks a shot: water keeps you safe, alcohol costs a sobriety point. Stay on your feet to win.

Built with Next.js, TypeScript, Canvas, and Zustand. Available in English, Azerbaijani, and Russian; change the language in Settings.

## Run locally

Install Node.js and npm, then run:

```bash
git clone https://github.com/F4IK05/PeakLabs-Hackathon.git
cd PeakLabs-Hackathon
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) in your browser.

## Build

```bash
npm run build
```

The static website is exported to `out/`, ready for static hosting.
